# Corner illustration

`einbaum-hands-leaves.png` is the original hands-and-leaves composition selected
and confirmed by the user on 2026-10-26, from their existing business-card assets.
The file is copied unchanged; only its placement and visible area are controlled
by the page layout.

The upper-right branches and clasped hands are displayed using a CSS crop of the
right-hand portion. The source image remains intact. On wide screens, the artwork
occupies the outer margin; narrower screens reserve a band above the navigation.
The empty alt text and aria-hidden wrapper identify it as purely decorative.

The muted green colors within the approved artwork are a scoped exception to the
site palette. Text, links and UI accents retain their original color tokens.
